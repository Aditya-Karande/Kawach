KAWACH

Privacy & collection

Choose exactly which browser activity the extension may record.

Collection

Website visitsRecords the domain and visit time.
Search queriesDetects supported search-engine query URLs.
Chat messagesDetects messages sent in chat-shaped inputs (WhatsApp Web, Messenger, Discord, and similar). Best-effort — matches on a "message box" pattern, not a fixed list of every app.
File uploadsRecords selected upload filename, type, size and destination page.
File downloadsRecords downloaded filename, type, size and source URL where available.
Form submissionsRecords form metadata only. Passwords, OTPs, card fields and values are never captured.
Page metadataRecords title/domain metadata. Raw page text is off by default.

URL & text

Protection

Protect sensitive sitesAutomatically skips domains that appear to be banking, authentication, medical or password-management sites.

Link to a parent account

Ask the parent for the pairing code shown on their SafeSignal dashboard's "Link a child" screen, then enter it below. This is a one-time code — pairing links this browser to their account and replaces the Child ID below.

Backend integration

Signals (searches, visits, chat messages, page text) are sent one at a time to /api/signals. Everything else (uploads, downloads, forms, page metadata) is still sent as a batch to /api/events for the local dashboard.
Enable backend syncRequires a running SafeSignal/Kawach backend.
